# Project Rules

## IMPORTANT
- Make ONLY the changes explicitly requested.
- Do not modify unrelated files.
- Do not refactor existing code unless I ask.
- Do not rename variables, functions, components, or files unless requested.
- Preserve the existing architecture.
- Before editing, identify the exact file(s) that need modification.
- If a change requires touching another file, explain why before changing it.
- Do not install new packages unless I explicitly ask.
- Do not change package.json unless required for the requested task.
- Do not rewrite working code just to improve style.

## Response style
- Be concise.
- Explain the bug first.
- Show the minimal fix.
- Do not generate the entire file unless requested.

## Coding preference
- Prefer minimal changes over refactoring.
- Preserve my existing coding style.
- When fixing bugs, change the smallest possible amount of code.
